# OpenTween Small Workbench Edition

OpenTween 3.15.1 を基にした非公式改修版です。実験的な個人開発として公開しています。
本家 OpenTween の公式配布物ではありません。改修版の問い合わせやログを本家開発者へ送らないでください。

## 改修におけるAIの利用

本改修のコード変更・調査・テスト・公開準備は、利用者の指示のもとChatGPT／Codexを用いて行いました。
利用者による実機での動作確認も行っています。これは本家OpenTweenや参照した第三者コードの開発方法を示すものではありません。
OpenAIによる公式配布・承認や、安全性・品質の保証を意味しません。

## サポートと利用条件

本改修版については、原則としてサポートを行いません。
質問への回答、不具合修正、機能追加、将来のXの仕様変更への対応は約束しません。
利用者自身の判断と責任で利用してください。ライセンスに定めるとおり無保証です。
認証Cookie、個人設定、投稿内容を含むログを公開しないでください。

## 機能と対応状況

アプリ内の表示名は **OpenTween SWB** です。以下は本改修版での確認状況です。

| 機能 | 対応状況・制限 |
| --- | --- |
| タイムライン取得 | 対応。解析処理を修正し、Recentでは前回取得位置まで最大3ページを追加取得 |
| 投稿・投稿の削除 | 実機で動作確認済み。二重投稿防止処理あり |
| リツイート（リポスト） | 実機で動作確認済み |
| 検索 | 取得・表示を実機で確認済み |
| ユーザーのタイムライン表示 | 実機で動作確認済み |
| 長文投稿の表示 | 実機で動作確認済み |
| 引用投稿の本文・画像 | 実機で動作確認済み。引用をさらに引用した投稿は2階層まで表示 |
| 自動翻訳 | 本文と引用先に対応。リンク・引用表示を維持し、訳文をキャッシュ |
| アンケートの表示 | 選択肢・結果の表示を実機で確認済み |
| アンケートへの投票 | **未対応**。Web版Xで投票してください |
| DM／チャットの取得・送信 | **未対応**。Web版Xをご利用ください |
| 取得漏れの完全防止 | **保証できません**。Xの応答にない投稿や、補完上限を超えた投稿は取得できない場合があります |

原版からあるすべての機能について、現在のXで動作することを確認したものではありません。
非公開Web APIの仕様やアカウント状態によって、対応済みの機能も利用できなくなる場合があります。

## 利用上の注意

認証Cookieはログインに使える秘密情報です。設定ファイルやエラーログを公開しないでください。
この版はXの非公開Web APIを使用し、Xの仕様変更で動かなくなることがあります。
Xの利用規約への適合やアカウント制限を受けないことは保証しません。
自動翻訳を有効にすると、表示する本文と引用元本文が外部翻訳サービスへ送られます。
保護された投稿を翻訳する場合にも外部送信されます。必要に応じて自動翻訳をオフにしてください。

## ビルド

Windows、Visual Studioの.NETデスクトップ開発環境、.NET Framework 4.8 targeting packを用意してください。
Visual Studioの開発者コマンドプロンプトで実行します。

    msbuild OpenTween/OpenTween.csproj /restore /p:Configuration=Release

出力先はOpenTween/bin/Release/net48です。配布時は設定、ログ、診断データを含めないでください。
原版の説明はREADME.upstream.mdを参照してください。
設定ファイルの暗号化は原版互換の共通鍵を使います。設定ファイルは秘密情報として保護してください。
